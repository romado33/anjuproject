# Implementation and migration handoffs

## Sales → Professional Services

- New customer implementation kickoff should generate: implementation checklist, integration requirements summary, risk register, and migration plan outline.
- **Jira**: Create epic under `IMPS` project with labels `implementation`, `migration`.
- **Teams**: Notify `PS-Kickoff` channel with summary and account owner.
- **Salesforce**: Log activity on Account and Opportunity; link to Jira epic.

## Data migration

- Discovery questionnaire, mapping spreadsheet, and validation plan are standard.
- Data quality issues may require Support + PS joint ownership until root cause is known.
